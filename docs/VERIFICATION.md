## 確認の途中で見つけて直したこと

- はじめにの画面で、ボタンの下に大きな空きができていた → ボタンを画面の下に固定
- きっかけの初期値が「決めない」になっていた → 何も選ばれていない状態から始める
- 選択中の項目（黒塗り）が「1分はじめる」と同じ強さで目立っていた → 選択中は薄い色とチェックの印にして、主ボタンと区別
- プランクの前腕が床の線と重なり、腕を伸ばした姿勢に見えた → 床の線を下げ、前腕を長く
- 腕立て伏せの「上」のポーズで、ひじが少し曲がっていた → 腕がまっすぐ伸びるように修正（テストを追加）
- 開始前の画面で、安全の注意がポイントの下にあった → 先に表示
- 画面の初回表示の直後に移動すると、移動を取りこぼすことがあった → ルーターを修正（回帰テストを追加）
- GitHub Actions のアクションが古い Node.js 20 で動いていた → 新しい版に更新

## まだ確認できていないこと（既知の制限）

- **実機**：iPhone の Safari、Android の Chrome での確認はしていません。特に次の機能は端末によって動き方が違います。
  - 音声ガイド（日本語の音声がない環境では話さず、効果音と画面で進みます）
  - 振動（iPhone の Safari は非対応）
  - 運動中に画面を消さない機能（Wake Lock。非対応の端末では画面に注意を出します）
  - ホーム画面への追加とオフライン表示
- **ほかのブラウザ**：Firefox と Safari（WebKit）では確認していません。
- **音声**：確認に使ったブラウザには日本語の音声がなく、読み上げは確認できていません。
- **スクリーンリーダー**：読み上げの順番やラベルは、コード上で設定しただけで、実際の読み上げ（VoiceOver・TalkBack）では確認していません。
- **利用者のテスト**：初心者に使ってもらうユーザビリティテストはまだです（タスク案はレビューの「10. 検証の進め方」）。
