# 1分筋トレ（kintore-habit）

毎日じゃなくていい。週2〜3回、1分から始める筋トレ習慣のウェブアプリです。

- 公開URL：https://daisuke-awaji.github.io/kintore-habit/
- ログイン不要。記録はブラウザ（localStorage）にだけ保存され、外部には送信されません。

> 現在、実装中です。計画は [docs/PLAN.md](docs/PLAN.md)、実装計画は [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md) を参照してください。
> 設計の前提は、UIモックのレビュー（[docs/usability-review.md](docs/usability-review.md)）にもとづいています。
